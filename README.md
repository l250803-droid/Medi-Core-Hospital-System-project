\# MediCore Hospital Management System



\## Project Description

MediCore is a Hospital Management System developed in C++ using Object Oriented Programming concepts and SFML 3.0.0 for GUI.



The system supports:



\- Patient Login

\- Doctor Login

\- Admin Login

\- Appointment Booking

\- Appointment Cancellation

\- Bill Management

\- Prescription Management

\- Doctor Management

\- Security Logs

\- Patient Archive System



The project uses:

\- File Handling

\- OOP Concepts

\- Exception Handling

\- Dynamic Memory

\- SFML GUI



\## Technologies Used

\- C++

\- SFML 3.0.0

\- Visual Studio 2022
